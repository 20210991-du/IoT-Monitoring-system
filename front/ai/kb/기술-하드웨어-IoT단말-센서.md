# 하드웨어 — IoT 단말 & 센서 (옴니솔루션 제공)

> 하드웨어·통신 인프라는 협력사 **㈜옴니솔루션** 제공(우리 팀 개발 범위 아님). 우리는 데이터만 활용. → [[회사_QA로그]]

## 단말 (Terminal Box)
- `TB24-250401 ~ TB24-250455` (총 55대, 군산도시가스 SITE_ID=2). 1시간 주기 계측 + 12시간 burst 송신.
- `DEVICE_STATUS` 1=정상 / 0=중지.

## 센서 (단말당 평균 8종)
방식전위(mV)·AC유입(mV)·희생전류(mA, **희생양극 2대 406·407만**)·온도(℃)·습도(%)·통신품질(수신감도 dBm) + 가스누출(%LEL)·수위·배터리·충격.

## 방식(부식방지) 방식
- **외부전원 방식**(대부분, 정류기로 직류 공급) / **희생양극 방식**(2대만, 마그네슘/아연 양극). → [[용어집]]
- 기준: 방식전위 -850mV(이하 보호) · AC유입 200mV↑ 부식가속·500mV↑ 즉각차폐 · 통신 -115dBm 이하 불가.
