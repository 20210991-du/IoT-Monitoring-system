- 주기: **1시간**

2. 수집원본데이터
3. 방식전위
4. AC유입
5. 희생전류
6. 온도
7. 습도
8. 통신품질

## 센서 필드

→ 상세 표: [[요구사항#6개-센서-필드]]

## 그룹핑 기준

**정류기 단위** — 시설번호 앞자리가 아님.
- 동일 지역 · 동일 배관 · 동일 정류기 = 1 그룹
- 결정: [[ADR-004-정류기단위-그룹핑]]

## 전처리 파이프라인 (계획)

```
원본 Excel (샘플) / MS SQL Server KSCG (운영, read_only)
  ↓
필드 정규화 (6 센서)
  ↓
정류기 그룹 매핑 (외부 테이블)
  ↓
결측 처리
  ├── 희생전류: 해당 2개 기기만 유지, 나머지 null
  └── 통신품질: 룰 플래그로 분리, AI 입력 제외
  ↓
파생 피처 (diff1, dev24)
  ↓
그룹별 MinMaxScaler
  ↓
시퀀스 슬라이싱 (seq_len)
  ↓
LSTM AE 입력
```

## 주의 사항

### 확인된 특이 패턴

- **11/18~20**: 방식전위↑ + AC유입↓ 동시 → 기기 특정 후 정류기 단위 재검토 ([[회사_QA로그#Q1]])
- TB24-250436: 통신 -115 dBm
- TB24-250411: 방식전위 -801mV
- TB24-250418, 419: AC유입 3,703~4,218mV
