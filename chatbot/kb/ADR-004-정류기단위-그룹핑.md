# ADR-004 · 기기 그룹핑은 정류기 단위

## 맥락

- 초기에는 시설번호 앞자리 / 형식 컬럼으로 그룹핑 검토
- 하지만 동일 시설번호라도 실제 운영 단위가 다를 수 있음

## 회사 답변

> 시설번호 앞자리 / 형식 컬럼보다
> **동일 지역 · 동일 배관 · 동일 정류기** 단위로 묶는 것이 핵심.

→ [[회사_QA로그#Q3]]

## 결정

1차 그룹핑 기준: **정류기 단위**
- 지역 공유
- 배관 공유
- 정류기 공유

## 근거

- 정류기가 방식전위의 **실제 소스** — 같은 정류기를 공유하면 패턴이 동조
- 같은 구간이라도 단말 설치 위치에 따라 정류기가 다르면 방향이 달라짐 ([[회사_QA로그#Q1]] 답변 참조)
- 그룹 내 편차 기반 이상탐지 설계가 가능

## 파급

- `group_scalers.pkl` 의 "그룹" 정의가 곧 정류기 그룹
- **정류기 → 장비 매핑 테이블** 을 데이터 전처리 단계에서 구축 필요
- 이 테이블은 회사에서 받거나, 시설/배관 메타데이터로 추론
