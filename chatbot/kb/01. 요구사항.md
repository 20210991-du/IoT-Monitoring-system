# 04 · 요구사항 및 스펙

## 기능 요구사항

### 통합관제

- 분산된 IoT/설비 데이터를 **한 화면** 대시보드에서 모니터링
- 전국 단위 다수 기기의 상태를 한눈에 (KPI + GIS + 리스트)
- 장비별 드릴다운 (전체 → 구역 → 장비 → 센서)

### AI 이상탐지

- 실시간 센서 스트림에서 비정상 패턴 자동 판별
- **정상 / 관찰 / 이상** 3단계 분류
- 이상 원인의 **센서별 기여도** 제시 (TOP 3)

### 운영 지원

- 이상 감지 시 **실시간 알림**
- 이력 조회 + 필터링 + 검색
- LLM 기반 요약·설명문 (보조 기능)

## 데이터 스펙

### 확보 데이터

- 파일: `01_시설물_50개_샘플_데이터.xlsx`
- 장비 체계: **TB24-250401 ~ TB24-250455** (총 55개, 유효 50개)
- 시설번호: 1-178, 1-238, 2-010, 4-001 등
- 수집 주기: **1시간 단위**
- 데이터 기간: **2025-11-17 ~ 2026-03-18** (약 4개월)
- 시트 구성 (8개): 설치 및 분석정보, 수집원본데이터, 방식전위, AC유입, 희생전류, 온도, 습도, 통신품질

### 6개 센서 필드

| 필드 | 단위 | 설명 | AI 입력 |
|---|---|---|---|
| 방식전위 | mV | 배관 부식 방지 전위 | ✅ |
| AC유입 | mV | 교류 간섭 전압 | ✅ |
| 희생전류 | mA | 음극 방식 전류 | ⚠️ 2개 기기 한정 |
| 온도 | ℃ | 맨홀 내부 | ✅ |
| 습도 | % | 맨홀 내부 | ✅ |
| 통신품질 | dBm | 신호 강도 (음수, 클수록 나쁨) | ❌ 룰 기반 필터 |

입력 제외/분리 결정 근거:
- [[ADR-002-희생전류-분리처리]]
- [[ADR-003-통신품질-룰기반필터]]

### 센서별 정상 역할 · 이상 시 의미

| 센서 | 정상 역할 | 이상 시 의미 |
|---|---|---|
| 방식전위 | 배관이 부식되지 않도록 유지하는 방식 전압 | 너무 **높거나 낮으면 부식 위험** (기준선 ±편차) |
| AC유입 | 인접 송전선 등 외부 교류 간섭의 크기를 측정 | **높으면 절연 파손 가능성** 또는 유도 전압 과다 |
| 희생전류 | 희생양극 방식에서 양극이 소모되며 흐르는 방식 전류 | **0 에 가까우면 방식 기능 상실** (양극 소모 완료 가능성) |
| 온도 | 설치 환경 온도 | 환경마다 정상 범위가 달라 **절대값 판단 어려움**, 급변·편차가 더 중요 |
| 습도 | 설치 환경 습도 | **급상승 시 침수/밀봉 파손** 가능성 |
| 통신품질 | 단말의 신호 세기 (dBm, 음수) | **-115 dBm 이하 = 통신 불가** (룰 필터에서 처리) |

### 확인된 특이사항

- **희생전류**: 55개 중 **TB24-250406, TB24-250407** 2개 기기에서만 값 측정 (나머지는 외부전원 방식)
- **11/18~20 이상 패턴**: 방식전위 상승 + AC유입 하락 동시 발생 → 정류기 단위로 재검토 필요
- **TB24-250436**: 통신품질 -115 dBm 수준 통신 불량
- **TB24-250411**: 방식전위 -801mV (기준 미달)
- **TB24-250418, 419**: AC유입 3,703~4,218mV 급등
- 위도/경도 컬럼 존재, **실제 값 유효성 확인 필요** (GIS 기능 직결)

## UI 스펙

### 디자인 기준

- 화면: **1920 × 1080** (관제실 대형 모니터)
- 톤: **Bloomberg 터미널 스타일** (주식창 참고, 고령 사용자 배려)
- 다크 테마
  - 배경 `#0d1117`, 패널 `#161b22`, 테두리 `#30363d`
- 상태 색상
  - 이상 `#f85149` / 관찰 `#d29922` / 정상 `#3fb950` / 통신장애 `#8b949e`
- 폰트: Courier New (mono) 기반
- 정보 밀도 최대, 여백 최소

### 네비게이션 탭 7개 (KNE CP PLATFORM 참조)

1. 대시보드 — KPI + GIS + AI 추론 + 이벤트 + 요약
2. 위치관제 — 전체 GIS + 구역별
3. 장비이상이력 — 필터 + 이력 테이블
4. IoT TB — 전체 장비 상세 테이블
5. 데이터 분석 — 장비별 센서 시계열
6. AI 추론 — 추론 상세 + 모델 현황
7. 시스템 관리 — 설정, 알림, 사용자 관리
